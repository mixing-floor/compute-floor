# Released results

Every number in the paper can be traced to a file in this directory. Everything here was produced by
[`Code/run_experiment.py`](../Code/run_experiment.py) or [`Code/diagnostics`](../Code/diagnostics) on one
NVIDIA A100 (80 GB). All runs use scenario **S2_9R_9S** (9 real Pile subsets, 9 synthetic instruction corpora)
and seeds **0, 1, 2**. Losses are mean token cross-entropy in nats.

```
Results/
├── main/          output of run_experiment.py for the three compute tiers
├── figures/       per-method figures generated by Code/visualize_results.py from main/
└── diagnostics/   two instrumented runs that log the raw update signals
```

## `main/`: the three compute tiers

File names follow `<kind>_<TIER>_S2_9R_9S.<ext>`, where `TIER` is `HEAVY` (reported, pythia-160m),
`LIGHT` (pythia-70m) or `SUPER_LIGHT` (pythia-70m smoke test). A run has 7 reweighting rounds; round 0 is
the uniform start.

| File | Rows | Columns |
|---|---|---|
| `agg_<TIER>_S2_9R_9S_synth_share.csv` | method × round | `synth_share_mean`, `synth_share_std` (mass on the 9 synthetic domains), `l2_mean`, `l2_std` (L2 distance of *p* from uniform) |
| `agg_<TIER>_S2_9R_9S_final_weights.csv` | method × domain | `is_synth`, `weight_mean`, `weight_std` (final per-domain mixture weight; uniform = 1/18) |
| `agg_<TIER>_S2_9R_9S_weight_trajectories.csv` | method × seed × round × domain | `pretty` (domain name), `is_synth`, `weight` |
| `agg_<TIER>_S2_9R_9S_val_loss_trajectories.csv` | method × seed × round × domain | `pretty`, `is_synth`, `val_loss` (the signal every online method consumes) |
| `agg_<TIER>_S2_9R_9S_test_loss.csv` | method | `eval`, `test_loss_mean`, `test_loss_std` (aggregate over 18 domains), `real_mean`, `synth_mean` (held-out test split) |
| `results_<TIER>_S2_9R_9S.npy` | one dict | `per_seed` (full histories and per-domain test losses), `is_synth`, `pretty`, `cfg`, `seeds` |
| `flops_<TIER>.csv` / `.md` | budget line | `params`, `tokens`, `flops` (6·N·D), `note` (base per run, plus the DoGE and Skill-It surcharges) |
| `fig_<TIER>_S2_9R_9S_synth_share.png` | | synthetic share vs. round, ±1σ bands |
| `fig_<TIER>_S2_9R_9S_divergence.png` | | L2 from uniform vs. round, ±1σ bands |

Load a results file with:

```python
import numpy as np
res = np.load("Results/main/results_HEAVY_S2_9R_9S.npy", allow_pickle=True).item()
res["per_seed"][0]        # histories for seed 0
```

## `figures/`

These are the HEAVY-tier figures from `python Code/visualize_results.py`: synthetic share, divergence, final
weights, test loss, per-method weight evolution, and Aioli validation loss. Running the script with no
arguments regenerates these figures, plus the cross-tier figures, from `main/`.

## `diagnostics/`: signal-level instrumentation

These runs go beyond the paper's main tables. They wrap the same runner and record the raw score each update
reads, so the mechanism in the paper's Section 4 can be checked directly rather than inferred from the mixtures.

| Run | What it tests | Outcome |
|---|---|---|
| `pythia70m_heavy_s2/` | All six methods at the HEAVY protocol with **only** the model swapped to pythia-70m. | The family split repeats at a second model size: Group-DRO 0.199 ± 0.003, DoReMi-style 0.364 ± 0.001, Aioli 0.480, DoGE 0.525, Skill-It 0.533, Stratified 0.500. |
| `doge160_signal_heavy_s2/` | DoGE alone at Pythia-160m, logging every gradient inner product split by provenance. | The provenance gap in DoGE's normalised score changes sign from round to round (seed means -0.09, +0.06, -0.06), so DoGE has no persistent real-vs-synthetic pull. Final share 0.493 ± 0.008. |

Each run directory contains:

| File | Contents |
|---|---|
| `run_manifest.json` | resolved config, seeds, RNG protocol, changes from HEAVY, runner sha256, git commit, software and GPU environment |
| `seed_<k>.npy`, `results_<run>.npy` | per-seed and combined histories |
| `aggregate_trajectories.csv` | synthetic share and L2 per method and round (mean, std) |
| `final_mixture_summary.csv` / `final_mixture_aggregate.csv` | final shares and an exact split of squared L2 into between- and within-provenance parts |
| `weight_trajectories.csv`, `validation_loss_trajectories.csv` | per-domain trajectories |
| `test_losses_by_domain.csv`, `test_loss_seed_means.csv`, `test_loss_provenance_means.csv` | held-out test loss at three granularities |
| `doge_signals_by_domain.csv` | raw and normalised DoGE score per domain and step, split into alignment to real and to synthetic gradients |
| `doge_alignment_blocks.csv`, `doge_provenance_summary.csv`, `doge_seed_summary.csv` | provenance-block means of the same signal |
| `skillit_influence_graph.csv` | the learned 18 × 18 influence graph *A* (pythia70m run) |
| `skillit_signals_by_domain.csv`, `skillit_provenance_summary.csv`, `skillit_seed_summary.csv` | Skill-It scores (pythia70m run) |
| `aioli_column_sum_signals.csv`, `aioli_interaction_blocks.csv`, `aioli_provenance_summary.csv` | raw and EMA-consumed Aioli column sums and interaction blocks (pythia70m run) |
| `flops.csv` / `flops.md` | FLOP budget for the run |

`logs/` holds the full stdout of both runs. Absolute paths from the GPU server were rewritten to repo-relative
paths before release; nothing else in these files was edited. The manifests record a package hash under the
key `rebuttal_code_sha256`, the package's former name, which the current code writes as `diagnostics_code_sha256`.
